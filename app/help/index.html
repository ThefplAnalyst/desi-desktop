Help

Desi Desktop is a start page: Google search on top, and tiles with updates for South Asians in the US below. Everything you change stays in this browser.

Add, hide and move tiles

  • Hide a tile: select the × in the tile's top corner. On a computer it appears when you point at the tile or move to it with the keyboard.
  • Add a tile: select Customize at the top of the page, then switch a tile on under More tiles.
  • Move a tile: in Customize, use the up and down arrows next to a tile, or drag it with a mouse.
  • Your area: in Customize, pick one of 20 US metro areas for the weather and Desi Near Me. Desi Desktop never asks for your location.
  • Start over: in Customize, select Reset to defaults.

Filter tiles

Type in Filter tiles below the search box to show only tiles and rows that contain every word you type, in any order. For example, “india visa” shows rows that mention both words. Press Escape to clear the filter. Moving tiles is turned off while a filter is active.

What the labels mean

  • Updated 25 min ago: when that source last refreshed. Sources refresh on a schedule (about every 30 minutes to once a day); nothing here is live.
  • May be out of date: a source has not refreshed for longer than usual.
  • Useful links — not a live feed: a hand-picked list of websites, not headlines.
  • Curated by Desi Desktop: dates and lists we write and check by hand, such as cricket fixtures and festivals.

Where your settings are saved

Your tiles, their order, your area, layout and shortcuts are saved in this browser's local storage. There is no account and nothing is sent to us. Clearing your browser's site data resets Desi Desktop, and your settings do not follow you to other browsers or devices. If your browser blocks storage, changes last only for the current visit.

Open Desi Desktop when your browser starts

First copy this site's address from the address bar of the Desi Desktop home page.

Chrome

Settings → On startup → Open a specific page or set of pages → Add a new page, and paste the address.

Edge

Settings → Start, home, and new tabs → When Edge starts → Open these pages → Add a new page, and paste the address.

Safari (Mac)

Safari → Settings → General. Set Safari opens with to A new window, set New windows open with to Homepage, and paste the address into Homepage.

Firefox

Settings → Home → Homepage and new windows → Custom URLs, and paste the address. Then under General, make sure Open previous windows and tabs is turned off, so Firefox starts with Desi Desktop.

iPhone and iPad

Open Desi Desktop in Safari, select the Share button, then Add to Home Screen.

Android

Open Desi Desktop in Chrome, select the ⋮ menu, then Add to Home screen (or Install app).
